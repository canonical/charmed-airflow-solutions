# Hi Madrid 26.04!

We'll deploy the whole solution using our Terraform solution module as a base.

We'll deploy:
* `traefik-k8s` for ingress
* `git-integrator` for gathering DAGs from a git repo
* `airflow-kubernetes-executor` for executing tasks as Kubernetes Pods

## Prerequisites

* a `juju` controller bootstrapped on a Kubernetes cluster (k8s `kubectl` context configured)
* `terraform` >= 1.12.2
* `just` (recipes are defined in the parent module's `justfile`)
* `python3` with the `cryptography` package available (used by `setup_fernet_key.sh`)
* `yq` (used by `setup_env.sh` to parse `juju show-model` output)

All `just` commands below are run from the parent module directory
(`modules/charmed-airflow-with-ingress-and-git-integrator/`).

## TL;DR — run the whole demo

```bash
just all
```

`all` chains `setup-env` → `apply` → `setup-fernet-key`. Cleanup is intentionally
not part of `all`; tear down separately with `just cleanup` when you're done.

## Step by step

### 1. Provision the model and namespace

`setup_env.sh` creates a fresh juju model and a Kubernetes namespace (both
suffixed with the same random hash), then writes the model UUID and namespace
into `demo/terraform_test_kubernetes_executor.tfvars`.

```bash
just setup-env
```

### 2. Deploy the charms with the Terraform solution module

```bash
just apply
```

`apply` runs `terraform init` (idempotent) and
`terraform apply -auto-approve -var-file=demo/terraform_test_kubernetes_executor.tfvars`.

This deploys:
* the core `charmed-airflow` stack (postgresql, pgbouncer, coordinator, api-server, scheduler, triggerer, dag-processor)
* `airflow-kubernetes-executor`, related to the coordinator
* `traefik-k8s`, related to the api-server's `ingress` endpoint
* `git-integrator`, related to the coordinator's `git` endpoint, pre-configured to track `apache/airflow` `airflow-core/src/airflow/example_dags` on `main`

### 3. Configure the Fernet key for the coordinator

`setup_fernet_key.sh` generates a Fernet key, adds it as a juju user secret,
grants it to `airflow-coordinator`, and points the `fernet_key_secret` config
at the secret's URI.

```bash
just setup-fernet-key
```

### 4. Tear everything down

`cleanup.sh` destroys the juju model, deletes the Kubernetes namespace, removes
the autogenerated terraform state/lock files, and reverts the edits
`setup_env.sh` made to the tfvars.

```bash
just cleanup
```
